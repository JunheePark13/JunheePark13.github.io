Content-aware seam carving

C · Algorithms

I implemented a content-aware image-resizing pipeline in C that removes low-energy vertical seams while preserving higher-detail regions. The program computes an RGB gradient-based energy map, uses dynamic programming to find the minimum cumulative-energy seam, backtracks to recover the pixel path, then constructs a new image with that seam removed. The process can be repeated iteratively to reduce image width one column at a time.

01 · Energy

Compute horizontal and vertical RGB finite-difference gradients and combine them into a per-pixel energy magnitude.

02 · Dynamic program

Build a cumulative-cost table where each pixel inherits the minimum reachable cost from the row above.

03 · Backtrack

Start from the minimum value in the final row and trace the connected minimum-energy seam upward.

04 · Remove

Allocate a new image one column narrower and copy every pixel except the selected seam pixel in each row.

Implementation detailsExplicit memory allocation, 2D indexing in flat arrays, image-buffer management, and iterative seam removal.
Boundary handlingThe gradient calculation wraps edge pixels to the opposite image boundary when evaluating neighbours.
Core ideaResize based on image content rather than uniformly scaling every feature.

Cardboard bridge

Structures · Build & test

For a structural design project, I designed and built a bridge from cardboard and tested it to failure under load. The final bridge withstood more than 400 N, turning a simple material into a useful exercise in geometry, load paths, fabrication quality, and the gap between a design on paper and a structure that survives a physical test.

What mattered: the result came from using geometry and construction strategically rather than relying on material strength alone.

Electronic-pen accessibility concepts

Praxis I · Human-centred design

In Praxis I, I worked on concepts intended to make electronic pens more comfortable and accessible to use. The work included devices aimed at improving finger mobility and adding padding/support around the pen interface, with the design process focused on adapting a common product around user needs rather than asking the user to adapt to the product.

Design lesson: small mechanical changes to grip, support, and contact geometry can matter when the real constraint is the way a person physically interacts with the device.

Convertible solar-panel self-cleaning system

Mechatronics · Sustainability

I also designed and built a solar-panel concept that combined automatic orientation with a self-cleaning belt mechanism. The system rotated the panel based on perceived light intensity so its orientation could respond to changing illumination, while the belt system provided a mechanical way to clear the panel surface.

SensingLight-intensity feedback informed the panel orientation.
ActuationThe panel rotated rather than remaining fixed in one orientation.
Maintenance conceptA moving belt provided an integrated self-cleaning mechanism for the panel surface.

Across these projects: the common thread was moving between different kinds of engineering problems—writing low-level C, building and load-testing structures, designing around human use, and integrating sensing with moving hardware.
